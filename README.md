# kidos-social

KIDOS SOCIAL is a free kid-focused social video platform concept with a familiar video-platform layout.

## Main Features

* For You home page
* Videos
* Shorts
* Channels
* Search
* Following
* Community posts
* Upload videos
* Upload Shorts
* Live Control Room
* Live chat
* Chat moderation
* Watch history
* Parent-assisted account creation
* Browse without an account
* Dark desktop layout

## Everything Is Free

KIDOS SOCIAL is designed to be completely free.

There is:

* No Premium plan
* No paid subscription
* No paid membership
* No paywall
* No locked creator features
* No payment required to upload
* No payment required to livestream
* No payment required to follow channels

Instead of paid subscriptions, users can simply **Follow** channels for free.

## Account Safety

Kids can browse KIDOS SOCIAL without creating an account.

Before creating an account, KIDOS SOCIAL asks the child to get help from a parent or guardian.

Public profiles should never include:

* Home address
* School name
* Phone number
* Private email address
* Exact location
* Passwords
* Other private information

## Live Safety

KIDOS SOCIAL livestreams can include:

* Game or screen sharing
* Microphone
* Camera
* Live chat

Camera and microphone features should be controlled carefully for younger users.

Live chat moderation can warn or restrict users for inappropriate behavior.

Example moderation:

* Mild words such as "stupid" or "dumb" can receive a warning
* Repeated rude behavior can receive a timeout
* Strong profanity can receive a temporary ban
* Severe harassment or dangerous behavior can receive a longer restriction
